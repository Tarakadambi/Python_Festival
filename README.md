# 🎉 Festival Sales Analysis using Python

## 📖 Overview
This project performs **Exploratory Data Analysis (EDA)** on festival sales data using Python in a Jupyter Notebook.  
The goal is to analyze sales performance during festival periods and identify patterns in customer purchasing behavior.

Festival seasons often influence buying behavior, and this project helps understand those trends using data analysis techniques.

---

## 🚀 What I Did
- Loaded and explored festival sales dataset  
- Cleaned and preprocessed raw data  
- Performed Exploratory Data Analysis (EDA)  
- Analyzed sales trends during festival periods  
- Identified top-selling products and categories  
- Visualized sales patterns using graphs  
- Extracted business insights from data
